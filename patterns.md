# UI Patterns

## Confirmation pages

- Use the shared `Header` and `Footer`.
- Center the content in a `max-w-[720px]` container on `bg-lr-neutral`.
- Use a `bg-lr-green` circular check icon, a `font-heading` blue title, muted explanatory copy, and a blue primary return link.

## Event registration pages

- Use the shared `Header` and `Footer` with a centered white event hero and a `bg-lr-neutral` registration section.
- Keep the event title, date, and format above one `max-w-[640px]` registration container.
- Render provided Luma embed URLs in an accessible, responsive iframe; when an embed URL is pending, retain the same container with a clear registration placeholder.
